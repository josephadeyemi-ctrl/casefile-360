# NexaCore Technologies: company profile and organizational structure

NexaCore Technologies is a fictional Nigerian managed-services and cloud hosting company with about 250 employees. It is the environment that CASEFILE 360 investigates; it is not the application.

## Company profile

| Attribute | Value |
| --- | --- |
| Founded | 2014 |
| Head office | Victoria Island, Lagos |
| Second office | Wuse II, Abuja |
| Services | Managed IT support, cloud hosting, and business software for small and mid-sized companies |
| Customers | About 180 business customers, mostly in finance, retail and logistics |
| Working hours | 08:00 to 17:00 WAT, Monday to Friday, hybrid (three office days) |
| Email and identity | Microsoft 365: Exchange Online for email, Entra ID for sign-in |
| Email domain | nexacore.example |

The Microsoft 365 choice is a project assumption. It decides what the synthetic email headers and sign-in logs look like.
